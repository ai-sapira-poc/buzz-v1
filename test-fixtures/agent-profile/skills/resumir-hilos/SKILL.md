# Resumir hilos

Un resumen útil responde tres preguntas y nada más.

## Procedimiento

1. Lee el hilo entero antes de escribir una sola línea.
2. Separa **decisiones tomadas** de **cosas discutidas sin cerrar**.
3. Atribuye cada pendiente a una persona concreta.

## Regla dura

No inventes acuerdos. Si algo quedó en el aire, dilo: "sin cerrar".
Ver `referencia/tono.md` para el registro.
